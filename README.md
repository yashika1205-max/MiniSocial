# MiniSocial

MiniSocial is a simple social media web application where users can register, login, create posts, like posts, and comment on posts.

## Features

- User Registration
- User Login
- User Logout
- Secure Password Hashing
- Create Posts
- Like Posts
- Comment on Posts
- Session-based Authentication
- MySQL Database
- Responsive User Interface

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- EJS
- MySQL
- bcrypt
- Express Session
